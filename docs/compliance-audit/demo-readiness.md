# Prontidão do Demo Day

## Pronto tecnicamente

- frontend e API publicados no Worker;
- dados sintéticos podem ser usados;
- fluxo de login, convite, agenda, solicitação e encaminhamento existe;
- gate impede cadastro/convite real sem configuração jurídica;
- sem cópia de dados reais para demo.

## Não fazer na demonstração

- usar e-mails, nomes ou relatos reais;
- ativar `pilot_enabled` sem aprovação;
- compartilhar tokens de convite em canal público;
- apresentar personagens fictícios como psicólogos reais;
- afirmar conformidade LGPD ou atendimento psicológico real.

## Procedimento de fallback

Manter contas e instituição sintéticas preparadas, testar login antes da apresentação e manter a experiência demonstrativa separada do fluxo real. Se a API falhar, apresentar dados locais sintéticos sem importar produção.
