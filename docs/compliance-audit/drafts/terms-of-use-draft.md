# RASCUNHO NÃO APROVADO — Termos de uso

Minuta sujeita a aprovação. O Acolhe é uma plataforma institucional de organização de solicitações de conversa; não é serviço de emergência, diagnóstico ou prontuário clínico. Usuários devem fornecer dados necessários, manter credenciais em sigilo e não inserir dados de terceiros desnecessários.

Profissionais devem manter registro profissional válido, sigilo e confidencialidade, usar dados apenas para a finalidade institucional e não redistribuir dados. Instituições devem limitar acessos, orientar usuários e comunicar incidentes. Identidade do controlador, regras de menores, retenção, foro e canal oficial permanecem `PENDENTE`.
