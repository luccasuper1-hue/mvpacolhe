# RASCUNHO NÃO APROVADO — checklist de piloto real

- [ ] controlador, encarregado e canal definidos;
- [ ] política/termos aprovados e versionados;
- [ ] instituição assinou responsabilidades;
- [ ] CRP verificado manualmente e profissional aceitou sigilo;
- [ ] fluxo de menores/responsáveis aprovado;
- [ ] retenção, backup, expurgo e incidentes testados;
- [ ] testes de autorização/IDOR/rate limit passaram;
- [ ] provedores e transferências avaliados;
- [ ] `PILOT_LEGAL_VERSION`, `PILOT_CONTROLLER_NAME` e `PILOT_PRIVACY_EMAIL` configurados;
- [ ] aprovação explícita para ativar operações reais.
