# RASCUNHO NÃO APROVADO — Termo profissional

O profissional declara que usará dados somente para a finalidade autorizada, manterá sigilo profissional, não copiará nem redistribuirá informações, protegerá suas credenciais e comunicará incidente ou acesso indevido. O CRP e a instituição devem ser verificados por responsável designado. Este texto não substitui contrato, código de ética ou orientação jurídica.
